# ScholarMark Citation Audit

ScholarMark Citation Audit adds one skill, `citation-audit`, that checks academic writing against the evidence you give it. Paste a draft and the source passages you have, and ask for an audit. Each claim, direct quotation, page locator, and reference gets a status, a confidence level, and a suggested next step. The report says what was checked and what could not be checked.

The skill works only on text in the conversation. It needs no account, connects to no service, and stores nothing. It does not invent quotations, page numbers, DOIs, or other citation details. If your app has web access, it can look up DOIs at doi.org and Crossref; otherwise DOIs are reported as not checked.

## Example prompts

- "Audit the citations in this paragraph and flag claims the sources don't support."
- "Check whether the quotes in my draft match the source text word for word."
- "Check the DOIs and page numbers in my reference list."

## Limitations

The audit can only judge evidence it can read. Missing, paywalled, or sign-in-only pages are reported as unverifiable. Page numbers can be confirmed only when the source text includes page markers. Treat the results as an aid to your own review, and check important findings against the original sources.
