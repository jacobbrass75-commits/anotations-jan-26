Most bibliography repair work is just intake done late: hunting for a chapter's page range in the week before submission, or guessing an access date you didn't write down. Recording metadata properly when a source first arrives takes a few minutes and removes that work entirely.

## Where to find metadata, in order of reliability

1. **The source itself:** title page, copyright page, the article's first page, the journal masthead.
2. **The publisher's page** for the work, or its DOI landing page.
3. **A library catalog record** (your library, or [WorldCat](https://search.worldcat.org/)).
4. **A database record or [Crossref](https://search.crossref.org/).**
5. **Bookstore listings, search snippets, AI tools:** last resort, always checked against 1–3.

Records from 3 and 4 can describe a different printing or edition than the copy you hold. See [tracking editions, translations, and versions](/guides/tracking-editions-translations-versions).

## Fields by source type

**All sources**
- [ ] Source type (book, journal article, chapter, thesis, newspaper, website, other). Choose the type of the work, not where you found it.
- [ ] Authors, all of them, in order, with name spelling from the source.
- [ ] Title and subtitle, from the title page or article heading.
- [ ] Publication date, for the version you used.
- [ ] DOI, if one exists. APA, for example, says to include a DOI for [any work that has one](https://apastyle.apa.org/style-grammar-guidelines/references/dois-urls).

**Books**
- [ ] Publisher, from the title page.
- [ ] Place of publication, if your style or edition requires it. Purdue OWL notes it's [no longer required in Chicago 18](https://owl.purdue.edu/owl/research_and_citation/chicago_manual_18th_edition/cmos_formatting_and_style_guide/chicago_manual_of_style_18th_edition.html) unless needed to avoid confusion.
- [ ] Edition, from the copyright page.
- [ ] Translator or editor, if any.

**Journal articles**
- [ ] Journal title (the container).
- [ ] Volume and issue.
- [ ] Page range of the article, from the first and last printed pages.

**Chapters in edited books**
- [ ] Chapter title and author.
- [ ] Book title, plus editors (not to be confused with chapter authors).
- [ ] Publisher and date of the book.
- [ ] Chapter page range.

**Theses and dissertations**
- [ ] Degree type (PhD dissertation, master's thesis), as labeled on the title page.
- [ ] Granting institution.
- [ ] Year.

**Newspapers and magazines**
- [ ] Publication name.
- [ ] Full date (day, month, year).
- [ ] Section and page for print, or URL for online.
- [ ] Any correction notice.

**Web pages**
- [ ] Site name and publishing organization.
- [ ] Publication or "last updated" date, if shown.
- [ ] URL.
- [ ] Access date, meaning the date you captured it (see [citing web sources with missing author or date](/guides/citing-web-sources-missing-author-date)).

**Archival items**
- [ ] Item description and date.
- [ ] Box, folder, collection, and repository (see [organizing scanned and archival sources](/guides/organize-scanned-archival-sources-ocr)).

## The three-minute intake routine

When a source arrives:

1. **Search your library first** to avoid creating a duplicate.
2. **Fill the fields above** from the most reliable place available.
3. **Write a one-line note** on why you added it and which question or section it serves.
4. **Set its role** in the project: evidence, background, or style reference (see [source library, projects, folders, and roles](/guides/source-library-projects-folders-roles)).
5. **Flag anything uncertain,** such as "year unclear: 2019 hardcover or 2021 paperback?", so it's resolved before you cite.

## Worked example: intake for two sources

**A journal article PDF.** *(Invented.)*
- First page header: *Journal of Gulf Labor History*, vol. 12, no. 2 (2021), pp. 70–95.
- Authors: Daniel Price, and a second author listed in the byline whom the database record omits. Record both.
- DOI: printed on the first page. Resolve it to confirm it leads to this article.
- Note: "Statutory timeline; evidence for seminar paper §1."

**A scanned chapter from an edited book.** *(Invented.)*
- You scanned pages 33–58 only. Photograph or scan the book's **title page and copyright page** too, because that's where the editor, publisher, year, and edition are.
- Chapter author: Grace Lin. Book: *Labor on the Water*, edited by Samuel Reyes.
- Publisher and year: from the copyright page, which shows the second printing date and the first publication year. Note both.
- Note: "Public opinion; quotes 1934 pamphlet (secondary). Check if original findable."

The scanned chapter shows the most common intake failure: scanning the pages you need and not the pages that identify the book.

## Intake in ScholarMark

ScholarMark's citation record has fields for source type (book, journal article, chapter, thesis, newspaper, website, or other), authors, title and subtitle, container title, editors, publisher, place, date, edition, volume, issue, page range, DOI, URL, and access date. From that record, it generates Chicago notes-bibliography, MLA, and APA output.

When you upload a document, ScholarMark can try to extract citation metadata from the document's text. Treat the result as a draft. Check each field against the source's title or copyright page, especially authors, year, and source type, because extraction can only find what the text contains and can misread it. Anything left blank will be missing from your citations.
